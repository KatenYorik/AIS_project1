# Шаг 2. Датасет: своя съёмка и открытый датасет

**Задание.** Использовать **и** открытый датасет, **и** собственный — не меньше 100–300
своих изображений, с разным светом, фоном, позами и ракурсами.

## Что сделано

### Собственный датасет — 946 кадров

1. **Отбор клипов.** Из 136 клипов `AIS\птицы\` отобрано 16: 9 в первую сессию, 7 во
   вторую. Листы-кандидаты, по которым выбирали клипы, — `kandidaty*.jpg`.
2. **Нарезка кадров** (`extract_frames.py`) через ffmpeg, **2 кадра в секунду**. Имя кадра
   `<клип>_t<время в десятых долях секунды>.jpg` несёт клип и порядок кадров. На нём
   держатся и честное деление, и марковский анализ, поэтому кадры не переименовываются.
   - `data\raw\` — 706 кадров, 9 клипов (первая сессия);
   - `data\raw2\` — 240 кадров, 7 клипов (вторая съёмка, другой день и свет).
3. **Разметка** — шаг 3. В трёхклассовый датасет попадает 792 кадра: feeding 180 /
   alert 463 / empty 149.

### Деление на обучение и проверку — по клипам

Соседние кадры одного клипа почти одинаковы. При случайном делении **все 16 клипов**
оказываются и в обучении, и в проверке, и точность завышается. Поэтому делится
**список клипов**, а не кадры.

- `split_by_clip` в `dataset.py` **написана Катей**. Воспроизводимо перемешивает клипы,
  первые `round(val_frac × n)` клипов целиком уходят в проверку. После сборки проверяется,
  что клипы в выборках не пересекаются.
- `split_help.py` — помощник по написанию этой функции: обзор клипов, подсказки, версия
  на C++, **десять тестов** с разбором каждого падения, сравнение зёрен.
- `primer_split.py` — учебный пример того же приёма на другой задаче.
- Зерно выбрано **до обучения**, по составу классов в проверке (перебор десяти зёрен), а
  не по метрикам модели.

При `seed 5`: 12 клипов в обучении, 4 в проверке.

| feeding | 123 | 57 |
| alert | 402 | 61 |

### Сборка датасетов — `prepare_data.py`

Главный сборщик. Раскладывает кадры по классам в обе схемы (`data\sorted_course3\`,
`data\sorted_fine\`), проверяет деление и собирает датасеты в `data\datasets\`. Кроме
основного `birds_v1_course3`, он собирает варианты для дополнительных экспериментов:
деление по кадрам, по эпизодам, без названных клипов, с назначенной вручную проверкой.
Список датасетов — в `data\README.md`.

### Открытый датасет — Visual WetlandBirds

Водно-болотные птицы, видео с покадровой аннотацией рамок (Zenodo).

- `wb_stream.py` вырезает птиц по рамкам, **не скачивая весь архив на 9,4 ГБ**. Он читает
  оглавление zip и по HTTP Range качает только нужные видео, по одному. Метка — **вид
  птицы**, а не поведение: в `behaviors_ID.csv` семь поведений, а в данных встречается
  восемь значений, и соответствие пришлось бы реконструировать.
  Итог — `data\datasets\pretrain\`: **1947 вырезок, 13 видов**.
- `dataset.py --classes auto` делит вырезки **по видео**:
  `data\datasets\pretrain_split\` — 1567 в обучении, 380 в проверке. У трёх видов все
  видео ушли в обучение, поэтому в проверке 10 видов, а не 13.
- `build_pretrain_set.py` — ранний вариант того же для уже скачанных видео.
- 314 кадров с неопознанным `species_id = 4` выброшены.

**Как использован.** Не смешан со своими кадрами — у WetlandBirds другое определение
«осмотра». Схема двухэтапная (`АРХИТЕКТУРА.md`): сначала сеть учится различать виды на
чужих данных, затем дообучается на своих трёх классах. Это итоговая модель, шаг 6.

## Как запускать

Из `C:\Users\kkhod\claude\AIS`. Пути в аргументах считаются от `AIS\data\`.

```powershell
python project1\step2_dataset\split_help.py --check        # 10 тестов split_by_clip
python project1\step2_dataset\dataset.py --check
python project1\step2_dataset\prepare_data.py --seed 5     # все основные датасеты
python project1\step2_dataset\prepare_data.py --seed 5 --random-split
python project1\step2_dataset\prepare_data.py --seed 5 --episodes 10 --guard 2
python project1\step2_dataset\prepare_data.py --seed 5 --drop-clips ryabinnik2686 --val-clips snegir2692,ryabinnik2686,kormushka2729

# открытый датасет (нужен pip install remotezip)
python project1\step2_dataset\wb_stream.py --root ..\wetlandbirds --by species --per-class 150 --per-video 40
python project1\step2_dataset\dataset.py --sorted datasets\pretrain --out datasets\pretrain_split --val-frac 0.2 --classes auto
```

`prepare_data.py` **перезаписывает** `data\sorted_*` и `data\datasets\birds_v1_*`. Уже
обученные модели от этого не меняются, но датасет, на котором они учились, будет
пересобран. При том же зерне он получится таким же.

`extract_frames.py --videos` — давать абсолютный путь: относительный считается от
`AIS\data\`.
