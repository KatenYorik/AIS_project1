# Шаг 5. Метрики оценки

**Задание.** Стандартные метрики Ultralytics: precision, recall, mAP, F1, матрица ошибок —
всё в экспериментах ClearML.

## Что сделано

### Две планки, а не одна

При делении по клипам состав классов в обучении и проверке разный. Тривиальных решений
поэтому два, и дают они разные числа:

| решение | accuracy | macro-F1 |
|---|---|---|
| «всегда самый частый класс обучения» (`alert`) | 0.299 | — |
| «всегда самый частый класс проверки» (`empty`) | **0.422** | 0.198 |

Планка — вторая, более сильная. У запусков с другой проверкой (`frozen_fixval`,
`frozen_ep10`, `small_100_random`, `pretrain_stage1`) своя константа, и сравнивать их
можно только по выигрышу над ней.

### Метрики парой

- **accuracy** — при перекосе классов её легко получить вырожденной моделью;
- **macro-F1** — среднее F1 по классам без учёта их размера. Константа даёт по нему
  0.198, поэтому именно macro-F1 показывает, выучено ли что-нибудь.

Пример: `small_33` даёт **самую высокую accuracy 0.426** из честных запусков и при этом
F1 = 0.000 по `feeding`. Лучший по accuracy оказался вырожденным.

**mAP не приводится намеренно.** Это метрика детекции: она усредняет точность по порогам
перекрытия рамок, а рамок здесь нет. Для классификации приводятся top-1 accuracy,
точность и полнота по классам, F1 по классам и macro, матрица ошибок. Всё это есть в
`data\results\*.json` и в ClearML.

### Сводная таблица — `svodka.py`

Собирает все `data\results\*.json` в одну таблицу: accuracy и macro-F1, выигрыш над
**своей** константой, F1 по каждому классу, попарные сравнения экспериментов и отдельно —
«цену псевдорепликации» (деление по клипам против деления по кадрам). Таблица в
разделе 12 отчёта совпадает с выводом построчно (13 строк).

### Разбор по клипам — `po_klipam.py`

Одно общее число прячет, что клипы разные. Скрипт прогоняет модель по проверочным кадрам
и считает долю верных, F1 и путаницу отдельно по каждому клипу. Ничего не обучает.
Раздел 8.5 отчёта — разбор модели `frozen_ep10`. Урок: пять клипов со стопроцентным
результатом одноклассовые, и модель, склонная отвечать `alert`, берёт их даром.
Содержательны только клипы со смешанным составом.

## Файлы

| файл | что делает |
|---|---|
| `svodka.py` | таблица по всем запускам, сравнения, цена псевдорепликации |
| `po_klipam.py` | качество модели по каждому клипу проверки |

Сами метрики считает `step4_baseline_model\train.py` при каждом запуске.
