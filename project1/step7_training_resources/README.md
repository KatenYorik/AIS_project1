# Шаг 7. Вычислительные ресурсы

**Задание.** Процессора достаточно — это дообучение. GPU, Colab и удалённые серверы
разрешены, но не обязательны.

## Что использовано

**Всё обучение — на процессоре ноутбука.** GPU, Colab и серверы не использовались.

| что | значение |
|---|---|
| процессор | AMD Ryzen 5 5500U with Radeon Graphics |
| устройство в ultralytics | `--device cpu` |
| окружение | Windows 11, Python 3.11.9, torch 2.13.0+cpu, ultralytics 8.4.136 |
| время одного запуска | 13–27 минут на 30 эпох |
| запусков | 13, из них этап 1 предобучения — 10 эпох |

Этого хватило, потому что:

- модель маленькая — `yolo11n-cls`, 1,53 млн параметров, 0,4 GFLOPs;
- выборка маленькая — 588 кадров своей съёмки и 1567 вырезок WetlandBirds;
- вход 224×224.

Длинные очереди запусков шли на ночь: `step6_experiments\vsyo.ps1` на время работы
запрещает компьютеру засыпать и пишет журнал.

**Задержка вывода** итоговой модели на том же процессоре — шаг 3 Проекта 2: onnxruntime
6,0 мс на кадр (165 кадров/с), PyTorch через ultralytics — 18,6 мс.
