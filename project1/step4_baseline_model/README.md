# Шаг 4. Базовая модель

**Задание.** Дообучить предобученную модель Ultralytics YOLO, архитектура на выбор.
**Все запуски — в ClearML.**

## Что сделано

| параметр | значение |
|---|---|
| архитектура | `yolo11n-cls`, 1,53 млн параметров, предобучение ImageNet (`data\yolo11n-cls.pt`) |
| вход | 224×224: масштаб по короткой стороне и центральная обрезка |
| обучение | 30 эпох, batch 32, оптимизатор выбран автоматически: AdamW, lr 0.00143 |
| зеркальная аугментация | **выключена** (`fliplr = 0`) во всех зачётных запусках |
| железо | процессор AMD Ryzen 5 5500U, 13–27 минут на запуск |
| журнал | ClearML, проект `AIS-birds` |

**Почему `n`-размер.** 588 обучающих кадров, обучение на процессоре. Модель больше
быстрее переобучится и дольше считается, а узкое место — число сцен, а не ёмкость сети.

**Почему без зеркала.** Отражение меняет местами лево и право, а в мелкой схеме есть
классы `head_up_turnL` и `head_up_turnR`. Для трёх зачётных классов это не так важно,
но настройки держатся одинаковыми, чтобы запуски были сравнимы.

**Базовый запуск** — `small_100`: вся обучающая выборка, обычная аугментация, полное
дообучение.

| | accuracy | macro-F1 |
|---|---|---|
| константа «всегда `empty`» | 0.422 | 0.198 |
| `small_100` | 0.358 | 0.305 |

Модель выше константы по macro-F1 и ниже по accuracy. Ошибка на обучении падает с 0.78
до 0.0008 — 588 кадров запоминаются наизусть, а точность на проверке стоит на
0.30–0.36. Это переобучение. С ним работают эксперименты шага 6.

## `train.py`

Один скрипт на все запуски; эксперимент задаётся флагами.

- Обучает через ultralytics. Веса пишет в `data\runs\classify\<имя>\`.
- **Метрики считает сам**: precision, recall, F1 по классам, macro-F1, weighted-F1,
  матрицу ошибок, сильнейшую константу на своей проверке. Сам — потому что умеет
  сворачивать предсказания мелких классов в зачётные (запуск `base`).
- Пишет всё в `data\results\<имя>.json` (формат — в `data\README.md`) и в ClearML.

| флаг | что задаёт |
|---|---|
| `--exp` | `small`, `aug`, `frozen`, `base`, `pretrain` |
| `--frac` | доля обучающих кадров (эксперимент 1) |
| `--aug` | `off` / `normal` / `strong` (эксперимент 2) |
| `--freeze` | сколько модулей заморозить; для `--exp frozen` по умолчанию 10 (эксперимент 3) |
| `--stage` | 1 или 2 для `--exp pretrain` |
| `--data`, `--pretrain-data` | датасет, по умолчанию `datasets\birds_v1_course3`, `datasets\pretrain` |
| `--tag` | приписка к имени запуска, чтобы не затереть прошлый |
| `--epochs`, `--batch`, `--imgsz`, `--device` | по умолчанию 30 (10 для этапа 1), 32, 224, cpu |
| `--no-clearml` | без журнала ClearML |

## Как запускать

Из `C:\Users\kkhod\claude\AIS`, пути от `AIS\data\`:

```powershell
python project1\step4_baseline_model\train.py --exp small --frac 1.0     # базовый small_100
python project1\step4_baseline_model\train.py --help
```

Запуск с тем же именем **перезаписывает** `runs\classify\<имя>\` и `results\<имя>.json`.
Для повторов — `--tag`. Нужна настройка ClearML (`clearml-init`) или `--no-clearml`.
