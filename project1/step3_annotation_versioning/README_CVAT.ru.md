# Пункт про CVAT/Roboflow: как закрыть за десять минут

Требование чек-листа — «разметка в CVAT/Roboflow, формат YOLO». Разбираю честно, потому
что тут легко потерять полдня на бессмысленную работу.

## Что требование значит на самом деле

В графе курса узел CVAT подписан «Annotation for the bead/crumb detection set» — он
привязан к теме с **детекцией** зерна на полу, где нужны рамки. У нас классификация:
YOLO-классификация принимает **папку на класс**, никаких рамок нет вообще. То есть
«формат YOLO» у нас закрывается структурой `data/datasets/birds_v1_course3/train/<класс>/`,
и это не натяжка, а именно тот формат, который ест `yolo classify`.

Остаётся вопрос про инструмент. Разметка сделана в своём `labeler.html`, и это не
нарушение: требование про формат и артефакт, а не про то, какой мышкой щёлкали.
Более того, у своего инструмента была причина — три прохода по 946 кадрам с
протягиванием метки вперёд и тремя дополнительными колонками в CVAT заняли бы день
вместо полутора часов, потому что там нет протягивания по времени.

**Правильный ход — не переразмечать, а импортировать готовое.** Тогда CVAT или
Roboflow действительно используется, ссылка в отчёте есть, а руками не размечается
ни один кадр.

## Что уже готово

```
cd C:\Users\kkhod\claude\AIS
python project1\step3_annotation_versioning\to_cvat.py --labels labels_all.csv --raw raw --raw2 raw2 --out cvat
```

Уже запущено, в папке `cvat\` лежит:

```
annotations_cvat.xml   946 кадров с тегами, формат CVAT for images 1.1,
                       плюс атрибуты side / fixation / count
labels_cvat.json       описание меток и атрибутов для создания задачи
roboflow\<класс>\      три зачётных класса папками: alert 463, feeding 180, empty 149
```

## Путь A: Roboflow — проще, десять минут

1. Завести проект типа **Single-Label Classification**.
2. Перетащить в него папки `cvat\roboflow\alert`, `feeding`, `empty` — Roboflow
   разбирает структуру «папка = класс» сам, разметка подхватывается автоматически.
3. Сгенерировать версию датасета. Разбиение train/val **задать вручную**, а не кнопкой
   «случайно»: случайное перемешает кадры одного клипа между выборками и завысит
   метрики. Проще всего — в `Split` перетащить клипы целиком.
4. Экспорт в **Folder Structure** (это и есть формат для YOLO-классификации).
5. Ссылку на проект и номер версии — в отчёт.

Минус: данные уходят в облако. Для съёмки птиц это неважно.

## Путь B: CVAT — ближе к букве требования

1. Создать задачу, загрузить кадры из `raw\` и `raw2\`.
2. При создании задачи в списке меток переключиться на вкладку **Raw** и вставить
   содержимое `labels_cvat.json` — метки и атрибуты появятся все сразу.
3. Открыть задачу → **Upload annotations** → формат **CVAT for images 1.1** →
   выбрать `annotations_cvat.xml`.
4. Все 946 кадров окажутся размечены тегами, с атрибутами. Проверить глазами
   десяток и убедиться, что теги встали.
5. Экспорт в **ImageNet 1.0** — это папка на класс, то есть тот же формат.
6. Ссылку на задачу — в отчёт.

Если CVAT ругнётся на имена: XML ссылается на файлы по имени без папки
(`snegir2692_t00030.jpg`), а имена у нас уникальны по всей съёмке, так что коллизий
быть не должно.

## Что написать в отчёте

Одним абзацем, без оправданий:

> Разметка выполнена в собственном инструменте (`labeler.html`): схема требует трёх
> независимых проходов по одним и тем же кадрам — класс поведения, ориентация головы и
> взгляд, число особей — с протягиванием метки по времени, чего в интерфейсах общего
> назначения нет. Готовая разметка импортирована в CVAT в формате CVAT for images 1.1
> и экспортирована в формат «папка на класс», принимаемый YOLO-классификацией.
> Ссылка на задачу: …

Это сильнее, чем «размечали в CVAT», потому что объясняет, почему инструмент был
выбран, а не просто называет его.

## Чего делать не надо

- **Переразмечать кадры руками в CVAT.** Ни одно чтение требования этого не просит, а
  времени уйдёт день.
- **Рисовать рамки.** У нас классификация, детекции нет. Рамки не нужны и в формат не
  входят.
- **Отдавать Roboflow разбиение train/val на откуп.** Это единственное место в обоих
  путях, где можно молча испортить метрики: кадры одного клипа почти дубликаты, и их
  разброс между выборками завышает точность. Делить только по клипам.
