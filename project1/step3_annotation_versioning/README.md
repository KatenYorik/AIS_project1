# Шаг 3. Разметка и версии датасета

**Задание.** Разметить всё в CVAT или Roboflow, экспортировать в формат Ultralytics YOLO,
версионировать датасет в ClearML — как минимум начальная и улучшенная версии.

## Разметка — сделана

**Инструмент — свой `labeler.html`.** Файл открывается в браузере, работает без
сервера. Свой, а не CVAT, по конкретной причине: разметка шла тремя проходами по одним и
тем же кадрам с протягиванием метки по времени. В CVAT этого нет, и то, что заняло
полтора часа, заняло бы день.

| режим (Tab) | что размечается | клавиши |
|---|---|---|
| 1 — классы | восемь классов поведения, все кадры | `1`…`8`, `Shift`+цифра — протянуть вперёд |
| 2 — взгляд и сторона | только кадры осмотра | `Q/W/E/R` — сторона, `F/D/S` — взгляд |
| 3 — число птиц | число птиц в кадре | цифры |

Выгрузки (`labels_mine.csv`, `intervals_mine.csv`) сведены **`merge.py`** в главный файл
**`data\labels_all.csv`**: 946 кадров, 16 клипов.

| колонка | что | заполнено |
|---|---|---|
| `label` | 8 классов поведения | все 946 кадров |
| `side` | сторона головы к камере: L / R / F / A | 66 кадров |
| `fixation` | смотрит ли на наблюдателя: yes / no / unk | 302 кадра |
| `count` | число птиц | 235 размечено, 711 выведено по правилу |
| `count_src` | «размечено» или «выведено» | — |

Правило для невыведенного `count`: вне кормушечных клипов птица одна. `no_bird` → 0,
остальное → 1. Колонка `count_src` не даёт выдать выведенное за размеченное.

| класс | кадров | | класс | кадров |
|---|---|---|---|---|
| `head_up_ahead` | 248 | | `head_up_turnR` | 109 |
| `no_bird` | 149 | | `head_up_turnL` | 106 |
| `ambiguous` | 132 | | `handling` | 67 |
| `head_down` | 113 | | `transit` | 22 |

Клип со снегирём сначала размечался интервалами. `expand_intervals.py` превращает
интервалы в покадровые метки на любой частоте (`data\intervals_snegir2692.csv`).

**Ошибка, которую уже совершали.** Правило «лево/право» в первой инструкции было
зеркальным. Птица, смотрящая вправо по экрану, показывает **правый** бок. Разметка
Кати была верной, ошибался ассистент. При сомнении — спрашивать.

## CVAT / Roboflow — подготовлено, не загружено

`to_cvat.py` переводит готовую разметку в форматы для импорта, переразмечать ничего не
нужно. Результат — в `data\cvat\`:

- `annotations_cvat.xml` — 946 кадров с тегами и атрибутами `side` / `fixation` /
  `count`, формат CVAT for images 1.1;
- `labels_cvat.json` — описание меток для создания задачи;
- `roboflow\<класс>\` — три зачётных класса папками: alert 463, feeding 180, empty 149;
- `images.zip` — кадры для загрузки.

Формат YOLO-классификации — «папка на класс» — это ровно `data\datasets\birds_v1_course3\`.
Рамок в этой задаче нет.

**Не сделано:** сам импорт в CVAT или Roboflow. Инструкции — `README_CVAT.ru.md`
(10 минут, Roboflow) и `CVAT_ПОШАГОВО.ru.md` (35–45 минут, CVAT). Если не загружать,
написать в отчёте, что разметка велась собственным инструментом с экспортом в формат
CVAT, и почему.

## Версии датасета в ClearML

`clearml_versions.py` собирает две версии из готовой разметки:

| версия | состав | в ClearML | основание |
|---|---|---|---|
| **v1** — начальная | `data\raw\`: 706 кадров, 9 клипов | `birds` 1.0.0 — **603** кадра: alert 302, empty 137, feeding 164 | первая съёмочная сессия |
| **v2** — улучшенная | `raw\` + `raw2\`: 946 кадров, 16 клипов | `birds` 2.0.0 — **792** кадра: alert 463, empty 149, feeding 180 | вторая съёмка: другой день и свет |

В ClearML кадров меньше, чем в папках: после свёртки в три класса `transit` и `ambiguous`
отбрасываются.

v2 регистрируется **потомком** v1 (`parent_datasets`). ClearML хранит разницу и
показывает происхождение — поэтому датасеты держат в ClearML, а не в git (лекция 5).
Папки собираются в `data\datasets\clearml\`. Проект ClearML — `AIS-birds`.

**Проверено 14.09.2026** запросом к ClearML: обе версии есть, v2 зарегистрирована потомком
v1. Ссылок в отчёте пока нет — как их взять и открыть доступ, в `AIS\ИНСТРУКЦИЯ_CLEARML.md`.

Кроме v1 и v2, в ClearML лежат рабочие версии, которые `train.py` регистрировал при
запусках: `birds_v1_course3` 1.0.0–1.0.8, `birds_v1_random`, `birds_v1_episode`,
`birds_v1_course3_drop`, `birds_v1_fixval`, `birds_v1_fine`, `pretrain_split` 1.0.0–1.0.1.
